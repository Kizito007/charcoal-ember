# Charcoal & Ember starter

Exported from VibeStack on 2026-04-22.

## Stack
- Framework: React + Vite
- Styling: Tailwind CSS with the Charcoal & Ember design tokens
- Fonts: Outfit (heading) / Figtree (body)
- Icons: ph via @iconify/react
- Style: vibe-stack
- Atmosphere: grid

## Run it
```bash
npm install
npm run dev
```

## What's included (starter)
- Full Vite starter, ready to install and run
- Style-aware themed landing rendered at /
- Iconify pack installed

## Tokens
All colors are HSL CSS variables defined in `src/index.css`. Tailwind classes
like `bg-background`, `text-foreground`, `bg-primary`, `font-heading` and
`font-body` map to those tokens.

## Want the animations and 3D back?
This starter is static on purpose so it builds anywhere. To re-add the
framer-motion, kinetic typography, and scroll effects you saw in the live
preview, open **PROMPT.md** and paste it into your AI coding tool (Lovable,
Cursor, Claude Code, v0). It contains a per-style recipe.

## Adding more icons
See **ICONS.md** for a pack- and style-aware snippet plus a drop-in
`<Icon />` wrapper component tuned to this theme.

Enjoy.
